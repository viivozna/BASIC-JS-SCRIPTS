Завдання 7 — Міні-банкомат
Користувач має баланс:
let balance = 10000;

Показувати меню:

1. Show balance
2. Deposit money
3. Withdraw money
4. Exit

Користувач вибирає дію.
Програма працює доти, доки користувач не вибере 4.

1
Показати баланс.

2
Запитати суму поповнення.
Вона повинна бути більшою за 0.

3
Запитати суму зняття.
Перевірити:

- сума > 0;
- сума не перевищує баланс.
  Якщо все добре — відняти її від балансу.

4
Завершити програму.
Наприкінці: Thank you for using our ATM!

Завдання 8 — Система замовлення
Зроби програму, де є:
let products = [
{ name: 'Laptop', price: 35000, stock: 5 },
{ name: 'Phone', price: 22000, stock: 8 },
{ name: 'Tablet', price: 15000, stock: 3 },
{ name: 'Headphones', price: 4000, stock: 10 }
];
Користувач може неодноразово додавати товари до замовлення.

Програма повинна:

- показувати меню;
- дозволяти вибирати товар;
- перевіряти номер;
- перевіряти кількість;
- враховувати stock;
- додавати товари до замовлення;
- дозволяти продовжувати покупку;
- рахувати загальну суму;
- давати знижку:
  - < 20 000 → 0%;
  - 20 000–49 999 → 5%;
  - 50 000–99 999 → 10%;
  - 100 000+ → 15%;
- вивести повний чек.

Це вже задача, де тобі доведеться самій вирішити, які змінні створити, які масиви потрібні і де який цикл використовувати.
