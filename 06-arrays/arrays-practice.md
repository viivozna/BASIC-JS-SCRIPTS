ЗАВДАННЯ ДЛЯ ПРАКТИКИ МАСИВІВ

1. PUSH()
   Створи масив:
   let fruits = [‘apple’, ‘banana’];

Додай за допомогою push():

- orange
- kiwi
- mango
  Виведи масив.

---

2. POP()
   Є масив:
   let numbers = [10, 20, 30, 40, 50];

За допомогою pop():

- видали останній елемент;
- виведи початковий масив;
- виведи новий масив;
- виведи видалений елемент.

---

3. SHIFT() + UNSHIFT()
   Є масив:
   let users = [‘Anna’, ‘John’, ‘Kate’];

1. Додай ‘Mike’ на початок масиву за допомогою unshift().
1. Видали першого користувача за допомогою shift().
1. Виведи результат.

---

4. INCLUDES()

Є масив:
let fruits = [‘apple’, ‘banana’, ‘orange’, ‘kiwi’];

Запитай у користувача фрукт через prompt().
Перевір за допомогою includes(), чи є цей фрукт у масиві.

Якщо є:
‘We have this fruit!’

Якщо немає:
‘We don't have this fruit.’

---

5. INDEXOF()
   Є масив:
   let names = [‘Anna’, ‘John’, ‘Kate’, ‘Mike’];

Запитай у користувача ім’я.
Якщо воно є в масиві — виведи його номер для користувача.

Наприклад:
John is number 2

Пам’ятай, що індексація масиву починається з 0, тому для користувача потрібно показувати індекс + 1.

---

6. FOREACH()

Є масив:
let numbers = [5, 10, 15, 20, 25];

За допомогою тільки forEach():

- виведи всі числа;
- виведи квадрат кожного числа.

Результат повинен бути приблизно таким:
5 → 25
10 → 100
15 → 225
20 → 400
25 → 625

---

7. FOREACH() + IF

Є масив:
let numbers = [12, 7, 25, 4, 18, 31, 10];

За допомогою forEach():

- виведи тільки парні числа;
- порахуй їх суму;
- порахуй їх кількість.

---

8. MAP()

Є масив:
let numbers = [2, 4, 6, 8, 10];

За допомогою map() створи новий масив, де кожне число помножене на 3.

Очікуваний результат:
[6, 12, 18, 24, 30]

---

9. MAP() + ОБ’ЄКТИ

Є масив:
let products = [
{ name: ‘Phone’, price: 1000 },
{ name: ‘Laptop’, price: 2000 },
{ name: ‘Tablet’, price: 1500 }
];

За допомогою map() створи новий масив, який містить тільки назви товарів.

Очікуваний результат:
[‘Phone’, ‘Laptop’, ‘Tablet’]

---

10. FILTER()

Є масив:
let numbers = [1, 4, 7, 10, 13, 16, 20, 25];

За допомогою filter() створи новий масив тільки з парних чисел.

Очікуваний результат:
[4, 10, 16, 20]

---

11. FILTER() + ОБ’ЄКТИ

Є масив:
let products = [
{ name: ‘Phone’, price: 800 },
{ name: ‘Laptop’, price: 2500 },
{ name: ‘Tablet’, price: 1200 },
{ name: ‘Headphones’, price: 200 }
];

За допомогою filter() створи новий масив товарів, ціна яких більша за 1000.

---

12. FIND()

Є масив:
let users = [
{ id: 1, name: ‘Anna’ },
{ id: 2, name: ‘John’ },
{ id: 3, name: ‘Kate’ }
];

Запитай у користувача id.
За допомогою find() знайди відповідного користувача.

---

13. SOME()

Є масив:
let numbers = [12, 18, 25, 30, 42];

За допомогою some() перевір:
чи є хоча б одне число більше за 40?

Результат повинен бути true або false.

---

14. EVERY()

Є масив:
let numbers = [5, 12, 8, 20, 3];

За допомогою every() перевір:
чи всі числа в масиві додатні?

Результат повинен бути true або false.

---

15. REDUCE()

Є масив:
let numbers = [10, 20, 30, 40];

За допомогою reduce() знайди суму всіх чисел.

Очікуваний результат:
100

---

16. REDUCE() + ОБ’ЄКТИ

Є масив:
let products = [
{ name: ‘Phone’, price: 1000 },
{ name: ‘Laptop’, price: 2500 },
{ name: ‘Mouse’, price: 300 }
];

За допомогою reduce() знайди загальну вартість усіх товарів.

Очікуваний результат:
3800
